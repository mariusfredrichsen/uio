# Axioms for Events and Axioms of probability
- Sample space, set of all sample points
- Events, subset of the sample space
- Complement of event A is A^C and Pr(A^C) = 1-Pr(A)
- Axiom of probability, probability rule Pr which is a function mapping each event to a real number so that Pr(sample space) = 1
